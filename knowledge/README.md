# Canonical Knowledge Packs

This directory contains curated, source-attributed knowledge packs for Know Yourself. Keep original source material separate from paraphrase, synthesis, and user-specific chart evidence.

## Packs

- [Ra Uru Hu — Global Cycles (Parts 1–5)](ra-global-cycles/global-cycles-analysis.md): staged paraphrase/synthesis and record inventory.
- [Seed SQL](ra-global-cycles/seed-global-cycles.sql): idempotent data seed for the existing `ky_knowledge_*` schema.

## Rules

- Never present derived analysis as a verbatim source statement.
- Keep source provenance and rights status on every source.
- New knowledge records should remain staged/pending until human-reviewed.
- Speculative biological claims must be attributed and must not be treated as medical facts.
- Do not alter a user's canonical chart facts through general knowledge ingestion.
